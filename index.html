文以言文

背诵文言文，但不止于文言文

字·意·句三合一，配合艾宾浩斯复习与 AI 讲解，把每一个字词真正吃透。任何想背的内容，都能做成词单。

核心功能

从文言文出发，把「要背的东西」交给科学安排

📖

字·意·句三合一

每个词条包含字、释义、例句三层内容，把字放进语境里理解、记住，不再孤立死记。

🧩

三种背诵模式

支持「字意句」「QA 问答」「ABCD 选择」，换着方式加深记忆，也适合背单词、记知识点。

🧠

艾宾浩斯复习

学完自动进入复习计划，按 1、2、4、7、15 天间隔提醒温故；错过复习的词可手动加入重新学习列表。

✨

AI 讲解与生成

遇到不懂的字词随时唤起 AI 讲解；输入主题即可让 AI 生成词单（需自行配置 DeepSeek API Key）。

📚

精选内置词单

一键导入初中、高中高频实词、虚词、诗词名句；也支持手动创建或 AI 生成自己的词单。

📄

PDF 导出

词单一键导出 PDF，打印出来随身复习。学习与复习提醒按你的节奏自动安排。

常见问题

使用中遇到问题，先看看这里

支持哪些背诵模式？

支持三种词单类型：

· 字意句：字、释义、例句三合一
· QA 问答：问题和答案配对
· ABCD 选择：选择题形式，适合刷题

免费版有哪些限制？

免费版即可完整体验全部功能：每个词单最多 20 词，可创建 2 个词单，学习与复习合计每天 5 次。

付费方案是怎样的？

所有内购均为一次性买断、永久有效。可单独解锁「词数限制」「词单数限制」「学习次数限制」「复习次数限制」，也可以直接开通「全部付费功能」一次解锁所有权益。

更换设备或重装 App 后，可在付费页点击「恢复购买」找回已购权益。

「重新学习列表」是什么？

当某个词的复习间隔超过艾宾浩斯曲线要求时，App 会在复习时提醒你。确认「重新学习」后，这些词会加入重新学习列表，重新巩固后再回到正常复习周期。

AI 讲解和 AI 生成词单怎么用？

这两个功能依赖第三方 DeepSeek 服务，需要你在「设置 → AI 讲解」中填写自己的 DeepSeek API Key。相关请求只发送到你配置的 DeepSeek 服务，本应用不会另行收集或存储对话内容。

我的学习数据存在哪里？

词单、学习进度、复习记录、重新学习列表等数据均保存在设备本地。卸载 App 会删除应用沙盒内的本地数据，请谨慎操作。

如何导出 PDF？

在词单相关页面找到导出功能，即可将当前词单导出为 PDF 文件，方便打印或分享。

隐私政策

最后更新日期：2026 年 8 月 15 日

引言

欢迎使用「文以言文」（以下简称「本应用」）。我们非常重视您的隐私。本政策说明本应用如何处理您使用过程中产生的信息。除您主动使用的第三方服务外，本应用主要将数据保存在您的设备本地，不会上传到开发者服务器。

我们处理的信息

  • 本地学习数据：您创建或导入的词单、学习进度、复习记录、重新学习列表等，仅保存在设备本地（应用沙盒与系统偏好设置）。
  • 偏好与提醒：外观模式、音效、通知时间与提醒文案等设置仅保存在设备本地。
  • 系统通知：学习提醒与复习提醒为设备本地通知，仅在您授权后由系统调度，通知内容不经过任何服务器。
  • AI 讲解：当您使用 AI 讲解时，App 会将您输入的问题及最近对话记录发送至您自行配置的 DeepSeek 服务（api.deepseek.com），并使用您填写的 API Key 完成请求。除发送给该第三方外，本应用不会另行收集或存储对话内容。
  • AI 生成词单：当您使用 AI 生成词单功能时，App 会将您输入的词单描述及所选词单类型发送至您自行配置的 DeepSeek 服务，并使用您填写的 API Key 完成请求。除发送给该第三方外，本应用不会另行收集或存储该描述内容。
  • 内购：购买、恢复购买及退款由 Apple App Store 处理，本应用不收集您的支付信息；购买状态仅保存在设备本地。

信息的存储与安全

您的数据主要存储在设备本地，安全性取决于您的设备与系统设置。请妥善保管设备及您的 DeepSeek API Key。API Key 保存在设备本地的系统偏好设置中，不会上传给我们。

第三方服务

  • Apple：内购与恢复购买经由 StoreKit / App Store 完成，请参阅 Apple 隐私政策。
  • DeepSeek：AI 讲解与 AI 生成词单请求发送至您配置的 DeepSeek API，请参阅 DeepSeek 平台的隐私政策。该服务由您自行注册并提供密钥，相关费用与责任由该服务方承担。

信息共享与披露

我们不会向第三方出售、出租或交易您的个人信息。除上述 AI 讲解与 AI 生成词单请求发送至 DeepSeek、内购经 Apple 处理外，我们不会将您的数据上传、共享或披露给任何服务器或第三方。

您的权利

您可以在「设置 → 数据管理」中清空学习进度、复习记录与重新学习列表；在词单管理中删除词单；在「设置 → 通知」中关闭提醒；在「设置 → AI 讲解」中移除 API Key。卸载本应用将删除应用沙盒内的本地数据。

儿童隐私

本应用不面向 13 周岁以下儿童，我们不会有意收集儿童的个人信息。
